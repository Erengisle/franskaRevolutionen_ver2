# Franska revolutionen – interaktiv presentation

En interaktiv webbpresentation om varför den franske kungen inte kunde höja
skatterna, och hur det ledde fram till franska revolutionen.

## Presentationer

- **[index.html](index.html)** – *Revolutionen i korthet* (startsida): en
  förkortad, uppsnabbad version i fem kapitel som även täcker själva
  revolutionens förlopp och dess fem faser (konstitutionell monarki, krig
  och monarkins fall, republiken och Terrorn, Direktoriet, Napoleons
  maktövertagande).
- **[full.html](full.html)** – *Livrens bankrutt*: den fullständiga
  genomgången i sju kapitel (ståndssamhället, skatterna, statsskulden,
  maktens gränser, misslyckade reformer, vägen till 1789) plus en
  interaktiv övning där du sorterar orsakerna själv.

Filerna länkar till varandra så att man kan växla mellan snabbversionen och
den fullständiga versionen.

Sidan publiceras via GitHub Pages, så `index.html` är det som visas på
webbadressens rot.

## Arbetsblad

## Använda presentationen

Öppna `index.html` eller `full.html` direkt i en webbläsare – inget
byggsteg krävs.
